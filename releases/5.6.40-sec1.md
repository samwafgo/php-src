# PHP 5.6.40-sec1 — SamWaf community security backport

非 PHP 官方版本。基于 PHP 5.6.40，安全修订号为 sec1。

- 回移 CVE-2026-109618 / CVE-2026-109619 相关的内存错误退出及请求状态清理修复。
- 在 C 层禁用 Session 上传进度写入路径，普通文件上传与 Session 仍可使用。
- 增加 multipart part 数量限制及相关输入处理修复。

此发布由同一 Git 提交重新构建，附 15 个 Linux 环境的 web-release 核心包和 Windows VC11 x86/x64 × NTS/TS 四个核心包。
每个包记录源码提交、构建配置和验证范围；RELEASE-MANIFEST.json 将所有二进制关联到本 Tag，SHA256SUMS 可用于校验下载内容。

Linux 已执行限定范围 PHPT、运行库检查及普通 FPM 上传/Session 验证。Windows 已执行版本、PE 架构、TS/NTS、普通 CGI 上传及 Session 验证。Windows PHP 5.6 的整数宽度在 x64 下仍为 32 位。

这些是限定扩展的 community candidate 包：Linux web-release 缺少 OpenSSL/cURL/GD/ZIP 等；Windows core 包缺少这些扩展及 Apache 模块，需匹配架构的 VC++ 2012 Runtime。不要作为已有宝塔 PHP 安装的直接覆盖包。
完整 PHPT、IIS/Apache 集成、漏洞利用回归及生产验收不包含在本发布的通过结论中。

源码 tar.gz/zip 为 Git 源码打包，需要按仓库 CI 执行 buildconf 与生成解析器准备；安全补丁及各构建清单同时提供。
后续 sec2、sec3 会累积包含先前修复；已发布 Tag 和附件保持不变。
